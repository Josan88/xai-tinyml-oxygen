# ieee-paper-figures-named

One-column (235 pt) versions of two analysis figures for the IEEE A4 draft, drawn by `scripts/make_ieee_paper_figures.py` from `outputs/analysis-lamaakal-style-v1/` (`d_global_attribution.csv`, `d_case_studies.csv`). Nothing is recomputed. Explainer: mean-perturbation (training-mean replacement), in-sample on the shipped headers. `manifest.json` records input hashes and the plotted selections.
